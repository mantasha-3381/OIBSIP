# Temperature Converter Website

## Project Overview

This project is an interactive temperature converter website created as part of the Oasis Infobyte Web Development & Designing internship.

The website allows users to enter a temperature and convert it between Celsius, Fahrenheit, and Kelvin.

## Features

- Numeric temperature input
- Celsius, Fahrenheit, and Kelvin unit selection
- Conversion to all three units
- Convert button for calculations
- Input validation for invalid or empty values
- Absolute zero validation
- Clear error messages
- Responsive design for desktop and mobile devices
- Clean and centered user interface

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Conversion

The converter uses standard temperature conversion formulas to calculate the results between Celsius, Fahrenheit, and Kelvin.
