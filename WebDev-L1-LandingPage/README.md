# Nova Landing Page

## Project Overview

Nova is a modern and responsive landing page created as part of the Oasis Infobyte Web Development & Designing Internship.

The landing page presents Nova as a simple productivity service designed to help users organize their goals, manage their time, and stay focused.

## Features

- Sticky navigation bar
- Hero section with headline and call-to-action button
- Features section with three feature cards
- About section
- Contact and social media links in the footer
- Smooth scrolling navigation
- Responsive design for desktop and mobile screens
- Consistent colours, typography, spacing, and layout

## Technologies Used

- HTML5
- CSS3
