# Unit Converter Application

## Description
The Unit Converter is an Android application developed using Java and XML in Android Studio. It allows users to convert values between different units.

## Features
- Converts length units such as centimetres, metres and kilometres.
- Converts weight units such as grams, kilograms and pounds.
- Converts temperature units such as Celsius, Fahrenheit and Kelvin.
- Allows users to select the measurement category.
- Provides From Unit and To Unit dropdowns.
- Validates empty or invalid input using Toast messages.
- Displays the converted result with the unit label.

## Technologies Used
- Android Studio
- Java
- XML
- Android SDK

## How to Run
1. Open the project in Android Studio.
2. Wait for Gradle synchronization to complete.
3. Start an Android emulator or connect an Android device.
4. Run the application.
5. Select a category, enter a value, select the source and target units, and press Convert.

## Project Structure
- `MainActivity.java` – Contains the conversion logic and user interaction.
- `activity_main.xml` – Contains the user interface layout.
